# Halcyon

A holiday desk that shortlists three trips from London. The prices were read from public operator and agent listings on 10 October 2026. Each card links back to the listing it came from, and says when a fare is a from-price, a different month, or a date the listing never printed.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Next prints. The desk runs in the browser: pick a month, a party, a budget and a style, then shortlist three holidays.
